# Arrowlogy

Arrowlogy is a free, open-source (AGPL-3.0) video editor for macOS (Apple Silicon) that you control by conversation. An AI assistant cuts video, audio, and captions right on your Mac's hardware. Built on top of [OpenChatCut](https://github.com/0xsline/OpenChatCut), which is licensed under the same terms; both projects are independent.
